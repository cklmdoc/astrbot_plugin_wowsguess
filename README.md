# WowsGuess AstrBot 插件

将 [woyiba.com](https://www.woyiba.com/) 的《战舰世界》猜船玩法移植到 AstrBot 聊天会话中。

## 指令

| 指令 | 说明 |
| --- | --- |
| `/猜船 开始 [普通\|困难] [等级/范围]` | 在当前私聊或群聊会话新开一局（默认普通）；可限制答案等级，例如 `V`、`Ⅷ`、`8-10` 或 `VIII-X`；群聊存在进行中游戏时必须先结束该局。 |
| `/猜船 猜 <舰名/英文名/代码/别名>` | 提交一次猜测；可用中文、英文、代码或中文别名。 |
| `/猜船 状态` | 查看本局已猜记录与剩余次数。 |
| `/猜船 放弃` | 结束本局并公布答案。 |
| `/猜船 帮助` | 显示使用方法和判定规则。 |
| `/猜船 刷新数据` | 从 woyiba.com 下载最新公开题库数据；仅 AstrBot 管理员可用。 |

每局最多 8 次。开始游戏时可指定答案船等级，例如 `/猜船 开始 普通 V` 或 `/猜船 开始 普通 8-10`；每次 `/猜船 猜` 默认会生成一张 4×3 的属性多宫格卡片：🟩 是精确命中、🟨 是接近、⬆/⬇ 表示答案数值更高/更低、⬜ 是不匹配。群聊内有进行中游戏时，必须先猜中、耗尽次数或执行 `/猜船 放弃`，才能开始下一局。

## 卡片展示

- 默认 `render_cards=true`：`/猜船 帮助`（或直接 `/猜船`）同样通过 AstrBot 的 `html_render()` 生成深色指令卡片，每条命令独立呈现；管理员指令会显示“管理员”标记。
- `/猜船 猜` 会生成一张 4 列 × 3 行的属性多宫格卡片：🟩 是精确命中、🟨 是接近、⬆/⬇ 表示答案数值更高/更低、⬜ 是不匹配。
- 如果图片渲染服务不可用，插件会自动回退到对应的纯文本内容，不会中断本局游戏。
- 可在插件配置中关闭 `render_cards`，强制使用纯文本。

## 数据和联网

- 首次加载会从 `https://www.woyiba.com/data/` 下载 `ships.json`、`attributes.json` 以及普通/困难题库；缓存保存在 AstrBot 的 `data/plugin_data/astrbot_plugin_wowsguess/`。
- 默认设置为启动时自动刷新一次。若离线但已有缓存，插件会继续使用缓存；若首次加载且网络不可用，`/猜船 开始` 会提示明确错误。
- 只使用网站公开的静态舰船资料；不调用每日挑战、个人统计或多人房间 API，不共享用户信息。

## 安装

将本目录放入 AstrBot 的 `data/plugins/astrbot_plugin_wowsguess/`，然后在 WebUI 重载插件。AstrBot 会按 `requirements.txt` 安装 `aiohttp`。

## 兼容性

`metadata.yaml` 声明 AstrBot `>=4.16,<5`。插件数据目录通过 `StarTools.get_data_dir()` 获取。

## 来源与实现说明

玩法、公开数据结构与数值判定规则通过对网站已公开前端资源进行静态分析得出，灵感/原站：<https://www.woyiba.com/>。

本插件为独立 Python 实现，不复制或分发原站 JavaScript、网页样式、图片或服务端代码。原站多人房间、每日排行榜与账号/统计系统未移植。
